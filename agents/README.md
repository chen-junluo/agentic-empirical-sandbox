# Cairnwork Role Adapter

The canonical role contracts live in the Cairnwork repository, not in this
sandbox. Keep this file as a pointer so this workspace does not maintain a
second copy that can drift.

Set `CAIRNWORK_ROOT` to the Cairnwork checkout and read:

- `${CAIRNWORK_ROOT}/agents/project_initializer.md`
- `${CAIRNWORK_ROOT}/agents/analysis_executor.md`
- `${CAIRNWORK_ROOT}/agents/research_planner.md`

Use this sandbox's `AGENTS.md` files for workspace-specific archive,
`panel_factory`, and `projects/` boundaries. Use the Cairnwork contracts for
initialization, Node execution, result verification, and research handoff.
